# 설계 산출물

| 종류 | 위치 | 현재 상태 |
|---|---|---|
| ERD | [erd](erd/README.md) | 작성 대기 |
| SA 설계문서 | [sa](sa/README.md) | 작성 대기 |
| 인프라 설계도 | [infrastructure](infrastructure/README.md) | 작성 대기 |

현재는 산출물 저장 구조를 만든 단계다. 설계 기록 Markdown과 별도의 ERD·SA·인프라 설계도가 생성되었다고 간주하지 않는다.

작성 시 편집 가능한 원본과 SVG·PDF·HTML 등 열람용 결과를 함께 관리하고 관련 설계·판단 문서를 연결한다. 논리 모델·물리 모델·목표 구성·실제 배포 상태를 명시한다.
